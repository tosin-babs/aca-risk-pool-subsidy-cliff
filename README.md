# The Subsidy Cliff and the Risk Pool: An Actuarial Model of Adverse Selection and Premium Stability in the ACA Individual Market

Models how the expiration of enhanced premium tax credits changes who stays in the ACA individual market, and what that does to morbidity, premiums and pool stability.

**Status.** Planned. Code and results will be published here as the
analysis is completed.
